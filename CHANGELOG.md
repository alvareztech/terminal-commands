# Terminol Changelog

## [Initial Version] - {PR_MERGE_DATE}

- "My Commands": a list of your own commands (with "Ping 8.8.8.8" as an example) that run in Terminal, plus a form to create new ones (multiline commands supported).
- "Create Quicklink for Hotkey" action, so a saved command can be bound to a global hotkey through a Raycast quicklink.
