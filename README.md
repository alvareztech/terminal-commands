# Terminol

Extensión de Raycast. Por ahora incluye un único comando, **Ping 8.8.8.8**, que abre la Terminal y ejecuta `ping 8.8.8.8`.

## Desarrollo

```bash
npm install
npm run dev
```

`npm run dev` abre la extensión en Raycast en modo desarrollo con recarga automática.

## Publicar

```bash
npm run lint
npm run build
npm run publish
```
